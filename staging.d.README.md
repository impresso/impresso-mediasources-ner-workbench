# staging.d

`staging.d/` is the default local staging root for generated workbench artifacts that should be easy to inspect from inside the repository but should not be committed.

Typical contents:

```text
staging.d/
  datasets/
    impresso-mediaagencies-ner-dataset/
  reports/
    curation_state.json
```

Generated by targets such as:

- `make publish-dataset`
- `make dataset-state`
- `make curation-state-json`

Override the root with:

```bash
make publish-dataset STAGING_DIR=/path/to/staging
```

The directory itself is ignored by git.
